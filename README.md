# Abeona

**Predominantly built with AI**

Abeona is the next version of the existing CTTrains Android transport and journey-planning app.

The existing source is being recovered from `Xhanti-mbasa/cttrains-api` at commit `10c260eabea53753cdf6911596c343ba8806f1c6`. Inspection and stabilisation will be proposed in a draft pull request. The complete UI redesign and monorepo restructuring follow selection of a visual direction.

Status: work in progress. No Google Play readiness or verified Abeona release build is claimed.
